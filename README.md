A dependency-free, faster reimplementation of the makefun-site 1.0.0 static site generator. `solve.js` exports `run(input)` returning the same output tree as the reference build, byte-for-byte; `main.ts` is the standard driver (reads `cases.json`, writes `answers.json`).

## Run it

```sh
MAKEFUN_INPUT_DIR=<dir with cases.json> MAKEFUN_OUTPUT_DIR=<out dir> node main.ts
```
